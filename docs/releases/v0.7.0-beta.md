# MangaCrisp v0.7.0-beta

MangaCrisp v0.7.0-beta adds local PDF reading to the Apple Silicon app while
preserving the existing archive-reader experience.

## Highlights

- Add unencrypted PDF files by drag and drop or the file picker.
- Import generates only the cover; the remaining pages render on demand.
- Color PDF pages stay in color through rendering and optional Real-CUGAN enhancement.
- PDF render and AI enhancement caches are bounded and can be cleared from the bookshelf.
- Archive imports reject path traversal, excessive entry counts, oversized entries, and extreme compression ratios.
- Managed imports use staging directories so failed work does not replace a valid book.
- Database migrations create a backup first.
- Privacy-safe diagnostics can be copied for issue reports without including paths or book names.

## Install

1. Download `MangaCrisp-v0.7.0-beta-macos-apple-silicon-standalone.zip`.
2. Unzip it and move `MangaCrisp.app` to Applications.
3. On first launch, Control-click the app and choose **Open**.

Python, uv, Terminal, and a separate Real-CUGAN installation are not required.
The package includes the required runtime, PDFium, the pinned Real-CUGAN engine,
models, and license notices.

This beta is ad-hoc signed and is not notarized by Apple.
