# MangaCrisp v0.6.0-beta

This release preserves color in AI-enhanced pages and adds direction-aware
mouse reading controls.

## Highlights

- Real-CUGAN output keeps its RGB color channels.
- Incompatible legacy grayscale display caches are removed automatically.
- Edge clicks turn spreads according to right-bound or left-bound reading.
- `Shift` + edge click moves one page.
- Center click toggles reading progress and file information.
- Right-click moves to the previous spread.
- Drag and double-click safeguards prevent unintended page turns.
- Mouse controls behave the same in windowed and full-screen reading.

## Distribution

The Apple Silicon standalone ZIP bundles MangaCrisp, Python, Qt, the pinned
official Real-CUGAN engine, its models, and required license notices. End users
do not need Python, uv, or Terminal.

This beta uses an ad-hoc signature and is not Apple-notarized. On first launch,
Control-click `MangaCrisp.app` and choose **Open**.
