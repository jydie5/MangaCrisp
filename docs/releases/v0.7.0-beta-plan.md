# MangaCrisp v0.7.0-beta release plan

Status: implemented for v0.7.0-beta. See [the release notes](v0.7.0-beta.md).

## Release goal

Add local PDF reading without weakening the existing archive-reader experience. The release introduces a shared page-source boundary so later Comic EPUB and OPDS work can reuse navigation, rendering, enhancement, and reading-state behavior.

## Included

- Shared publication/page-provider contract for folders, archives, and PDF
- Unencrypted local PDF import by file picker and drag and drop
- Cover-only work during import; remaining pages render on demand
- Raster, vector, mixed, grayscale, and color page preservation
- Existing right-to-left/left-to-right spreads, single-page offset, mouse navigation, fullscreen, and reading-state restore
- Immediate original rendering followed by optional Real-CUGAN enhancement
- Bounded rendered-page and enhanced-page caches with eviction
- Clear-cache and copy-diagnostics actions
- Explicit database schema versions, tested migrations, and recovery behavior
- Safe staged archive extraction with path, member-count, expanded-size, and compression-ratio limits
- English and Japanese labels, errors, help, and release notes

## Deferred

- Comic EPUB: v0.8.0-beta
- OPDS 1.2: v0.9.0-beta
- DRM, reflowable EPUB, OPDS 2.0, streaming reading, and cross-device position sync
- Automatic updates
- Stable-release branding while public packages remain unsigned

## Release gates

### Automated

- Unit tests pass on macOS
- Package import and syntax checks pass
- Library import, deletion, reading-state, and database migration tests pass
- Malformed and hostile archive/PDF fixtures fail safely and leave no partial library item
- A 300-page PDF opens after cover extraction without pre-rendering every page
- Render and enhancement caches stay within configured disk limits
- Packaged applications pass dependency, license, provenance, and extracted-package smoke checks
- No copyrighted test material, personal paths, credentials, or user library data are included

### Human validation

- Existing ZIP/CBZ/RAR/CBR/7Z/CB7 books behave as in v0.6.0-beta
- PDF import, cover display, first-page latency, color, spreads, original/enhanced comparison, fullscreen, mouse controls, and resume position work
- Rapid forward/backward navigation does not show a mixed original/enhanced spread
- Ten minutes of reading does not show unbounded memory, process, or disk growth
- The app starts from a clean user account without Python or uv
- macOS: M1 and M4 Pro are checked; additional Apple Silicon results are documented when available
- Windows packaging and hardware validation remain in the separate Windows release workflow

## Distribution policy

v0.7.0 remains a beta. macOS may continue as ad-hoc signed and not notarized only when the release page states this clearly. A broadly promoted stable release requires Developer ID signing and notarization.

## Issue order

3. PDF renderer packaging/license spike and decision record
4. PDF provider, cover import, lazy rendering, and bounded cache
5. Bookshelf/viewer integration, diagnostics, and bilingual UI
