# RAIV for mac v0.4.0-beta

RAIV for mac is now in beta. It is a free, open-source comic and image viewer
for Apple Silicon Macs with a local bookshelf, right-bound two-page reading,
and automatic Real-CUGAN enhancement.

The standalone ZIP contains RAIV.app, the verified Real-CUGAN executable, and
its models. End users do not need Python, uv, Terminal, or a separate AI engine.

## Highlights

- New RAIV application icon
- `O` toggles the visible spread between Original and Enhanced
- `H` opens keyboard help without requiring Shift
- Help includes project, issue-reporting, and optional support links
- English and Japanese interface and documentation
- Compatibility assessment for the A18 Pro MacBook Neo

## Install

1. Download the standalone ZIP and optionally verify its SHA-256 checksum.
2. Extract `RAIV.app` and move it to Applications.
3. On first launch, Control-click `RAIV.app` and choose **Open**.

This beta is ad-hoc signed but is not Apple Developer ID signed or notarized.
Apple Silicon Macs are supported; Intel Macs are not currently supported.
Physical-device testing on the A18 Pro MacBook Neo is still pending.

See [INSTALL.md](../../INSTALL.md) for detailed instructions.
