# MangaCrisp Windows Development Preview 0.7.1b0.4

This preview follows the successful b0.3 taskbar recovery check and makes the
default Windows capture controls as simple as the macOS two-key controls.

## Changes

- Capture now defaults to `Alt+C`.
- Undo now defaults to `Alt+U` (`U` for Undo).
- The previous three-key `Control+Alt+C` / `Control+Alt+Z` pair remains an
  alternative preset.
- The NVIDIA-conflicting `Alt+Z` preset is no longer offered.
- Capture behavior, taskbar recovery, numbering, PNG output, and CBZ/ZIP
  packaging are unchanged.

## 日本語

b0.3のタスクバー復帰確認は通過しました。このpreviewでは、Windowsの既定操作を
macOSと同様に2キーへ簡略化します。

- 直前取消は`Alt+U`です（UndoのU）。
- 従来の3キー`Control+Alt+C`／`Control+Alt+Z`は代替として残します。
- NVIDIA Overlayと競合する`Alt+Z`のプリセットは表示しません。
- 撮影処理、タスクバー復帰、連番、PNG、CBZ／ZIPの処理は変更していません。
