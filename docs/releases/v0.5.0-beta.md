# MangaCrisp v0.5.0-beta

MangaCrisp is the new name of the independent macOS manga and comic viewer
previously released as RAIV for mac.

## Highlights

- `MangaCrisp.app` application bundle
- `com.jydie5.mangacrisp` bundle identifier
- `mangacrisp_app` source package and `mangacrisp` command
- New MangaCrisp Application Support, cache, and default library locations
- Automatic migration of the previous settings, database, and AI cache
- Existing managed books and reading positions remain available
- Updated English and Japanese interface, help links, screenshots, and guides

## Upgrade from RAIV for mac

1. Quit `RAIV.app`.
2. Install and open `MangaCrisp.app`.
3. Confirm that the existing bookshelf and reading positions appear.
4. Continue using `MangaCrisp.app` after the migration.

MangaCrisp copies the small settings and database files into its new
Application Support directory. The previous default `~/RAIV Library` is renamed
to `~/MangaCrisp Library` on the same disk, so the books are not copied.
User-selected custom library locations are left unchanged.

The original ZIP, RAR, 7z, CBZ, CBR, and CB7 files are never deleted.

## 日本語

MangaCrispは、旧RAIV for macから名称を変更したmacOS向け漫画・コミック
ビューアです。初回起動時に旧設定と本棚データベースを新しい保存領域へ
引き継ぎます。旧既定の`~/RAIV Library`はコピーせず、同じディスク上で
`~/MangaCrisp Library`へ名前を変更するため、本と読書位置を保ったまま短時間で
移行できます。ユーザーが選択したカスタム保存先は変更しません。
