# MangaCrisp v0.7.1-beta

MangaCrisp v0.7.1-beta adds manual sequential screen capture on macOS and a
Single Page reader layout for images that already contain a full spread.

## Highlights

- Capture a user-selected fixed screen region as numbered, color-preserving PNG files.
- Use `Option+C` to capture and `Option+Z` to undo without bringing MangaCrisp to the front.
- Keep the bookshelf and capture controller hidden while operating the source application.
- Restore only the capture controller by clicking MangaCrisp in the Dock.
- Finish an active session safely after all pending PNG saves complete.
- Create one CBZ or ZIP and optionally add it to the bookshelf.
- Prevent repeated completion from creating duplicate archives or bookshelf entries.
- Keep the original numbered PNG files beside the finished archive.
- Switch the reader between **Spread (2 images)** and **Single Page (1 image)** with `V`.
- Apply original/enhanced comparison and AI enhancement to the visible single image.

## Capture permission

The first capture requires access under macOS **Privacy & Security > Screen &
System Audio Recording**. After enabling MangaCrisp, quit the application
completely and reopen the same installed copy. A second on-screen-content
prompt may appear after relaunch; allow it to complete setup.

Use capture only for screens you own or are authorized to save. MangaCrisp does
not automate page turning, bypass capture protection, or upload captured images.

## Validation

- 91 automated tests passed; two optional environment-dependent tests skipped.
- Apple Silicon human acceptance passed with 86 sequential captures.
- Audible and visual capture feedback, immediate PNG persistence, one-time
  archive completion, bookshelf import, and Single Page reading were verified.
- The standalone distribution audit verifies the bundled Real-CUGAN executable,
  models, dependency notices, app identifier, and ad-hoc signature.

## Installation

Download `MangaCrisp-v0.7.1-beta-macos-apple-silicon-standalone.zip`, move
`MangaCrisp.app` to Applications, then Control-click it and choose **Open** on
first launch. Python, uv, and Terminal are not required.

This beta is ad-hoc signed but does not have an Apple Developer ID signature or
Apple notarization.
