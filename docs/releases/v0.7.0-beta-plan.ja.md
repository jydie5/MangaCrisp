# MangaCrisp v0.7.0-beta リリース計画

状態: v0.7.0-betaで実装済み。内容は[リリースノート](v0.7.0-beta.md)を参照してください。

## リリース目標

既存の圧縮漫画ビューワ体験を壊さず、ローカルPDFを読めるようにします。Comic EPUBとOPDSでも、ページ送り、描画、AI補正、読書位置を再利用できる共通ページ基盤を先に導入します。

## 盛り込む機能

- フォルダ、圧縮ファイル、PDFで共通の出版物／ページ供給インターフェース
- ファイル選択とドラッグ＆ドロップによる、暗号化されていないローカルPDFの登録
- 取り込み時は表紙だけ生成し、残りは必要なページだけ描画
- ラスター、ベクター、混在、グレースケール、カラーの保持
- 既存の右綴じ／左綴じ、見開き、1ページずらし、マウス操作、全画面、読書位置復元
- 原画を即時表示し、必要な場合だけReal-CUGAN補正へ切り替え
- 上限と削除規則を持つPDF描画キャッシュ／AI補正キャッシュ
- キャッシュ削除と診断情報コピー
- DBスキーマ番号、移行テスト、失敗時の復旧手順
- 一時領域での安全な圧縮展開と、パス、項目数、展開後容量、圧縮率の制限
- 日本語／英語の表示、エラー、ヘルプ、リリースノート

## 次回以降へ送る機能

- Comic EPUB: v0.8.0-beta
- OPDS 1.2: v0.9.0-beta
- DRM、リフローEPUB、OPDS 2.0、ストリーミング読書、端末間の読書位置同期
- 自動更新
- 署名されていない配布物を正式版として扱うこと

## リリース条件

### 自動テスト

- macOSでユニットテストが成功する
- パッケージの読込確認と構文確認が成功する
- 本棚登録、削除、読書位置、DB移行のテストが成功する
- 破損・悪意ある圧縮ファイル／PDFを安全に拒否し、登録途中の本を残さない
- 300ページのPDFを全ページ事前描画せず、表紙生成後に開ける
- 描画キャッシュとAI補正キャッシュが設定容量を超え続けない
- 配布物の依存関係、ライセンス、来歴、展開後起動確認が成功する
- 著作権素材、個人パス、認証情報、ユーザー本棚データを配布物へ含めない

### ヒューマンチェック

- 既存ZIP/CBZ/RAR/CBR/7Z/CB7がv0.6.0-betaと同様に動く
- PDF登録、表紙、初回表示速度、カラー、見開き、原画比較、全画面、マウス操作、続きから読むが動く
- 高速な前後移動で、片側だけ原画／片側だけ補正済みの見開きにならない
- 10分連続読書でメモリ、プロセス、ディスク使用量が増え続けない
- Pythonやuvのない新規ユーザー環境で起動する
- macOSはM1とM4 Proを確認し、追加のApple Silicon結果も記録する
- Windowsのパッケージ作成と実機確認は、別管理のWindowsリリース工程で行う

## 配布方針

v0.7.0はベータを継続します。macOS版がadhoc署名・未notarizeのままの場合は、Releaseページで明記します。広く正式版として案内する前にDeveloper ID署名とnotarizationを必須とします。
