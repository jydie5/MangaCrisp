# Windows 読書・本棚UXのヒューマンチェック

2026-10-15の確認用ビルドです。製品バージョンは`0.7.1b0`のままですが、
ZIPの識別名は`0.7.1b0+win.ux.20261015.2`です。PR #47のちらつき修正を含み、
前回の`0.7.1b0+win.ux.20261015`および公開中のWindows b0.4とは異なります。
配布リリースとしては未公開です。2026-10-15に利用者から「問題なさそうです」と
この候補版の全体合格を受領しました。詳細項目ごとの実施報告はないため、
下の項目は再確認用の未チェック欄として残します。Linux実機合格を意味しません。

## 安全な準備

確認用ZIPを新しいフォルダへ展開し、その中の`MangaCrisp.exe`を起動します。
古いデスクトップのコピーや、公開中のb0.4を起動しないようにしてください。
本棚への登録・削除は`demo/`のPepper&Carrotだけを対象にします。
個人の本や、他の本をまとめて選択しないでください。

## 確認項目

- [ ] カラーのデモを開き、`O`で原画／補正版を切り替えてもカラーが保たれる。
- [ ] `F`で全画面にし、画像領域で約2秒静止するとカーソルが消える。
  マウス移動、キー入力、全画面解除、`Alt+Tab`でのアプリ切替後には戻る。
  設定パネル、メニュー、ダイアログ上では消えない。
- [ ] 画像領域の横幅中央20%を左クリックして読書情報を開く。
  「本棚へ」で全画面を解除して本棚へ戻り、再度開くと読書位置が保たれている。
- [ ] Ctrl+クリックでデモ2冊を選択でき、Shiftでも範囲選択できる。
  選択内の表紙を右クリックすると選択が維持され、メニューに2冊の削除と表示される。
  未選択の表紙を右クリックすると、その本だけが対象になる。
- [ ] デモ2冊の削除で確認ダイアログが1回だけ表示される。
  最初はNoでキャンセルし、本が残ることを確認する。
  削除を実行する場合も、対象がデモだけであることを読み直す。
  管理コピーは消えるが、元のデモZIPは残る。
- [ ] ページ送り後、表示中のページが遠い先読みの後回しにならない。
  通常の読書でもしばらく使い、原画表示やページ送りが引っかからない。
  前方先読みは読書間隔の中央値とGPU処理時間により6〜24ページで変わるため、
  10秒待つ操作1回だけで必ず6ページになるわけではない。後方保持は6ページ。
- [ ] 補正を有効にしてページを送り、10秒ほど静止する。
  先読み完了時に「補正版→原画→補正版」とちらつかないことを目で確認する。
- [ ] 必要ならデモ画面でキャプチャを試し、`Alt+C`／`Alt+U`と
  タスクバーからのコントローラ復帰が以前と同じであることを確認する。

ファイルが他のアプリでロックされて削除できない場合は、失敗を通知し、
その本の本棚登録を残します。成功した他の本の削除は反映します。
途中まで管理ファイルが削除されることはあるため、失敗後はロックを解除して再試行し、
必要なら残っている元ZIPから再登録してください。

## すでに行った開発側の確認

- Windowsの全体テスト: 186成功、9スキップ、5サブテスト成功（PR #47の回帰3件を含む）。
- 実際のWindowsファイルロックを使った一括削除の回帰テスト。
- 配布EXEでカラーの原画・補正済み表示、全画面でのアイドル時カーソル非表示、
  オーバーレイの本棚復帰、Shift選択、右クリックの2冊メニュー、削除確認とキャンセル。
- PR #47入り配布EXEと32ページの生成画像で、先読み12→6→12ページの変化を確認。
  ページ送り直後と10秒後の補正済み表示、および途中で先読み完了した状態を確認。
  スクリーンショットの比較は連続フレーム測定ではないため、この開発側の記録だけでは
  瞬間的なちらつきなしの証明にはしない。
- 新ZIPの配布監査と、開発ツールを除いた環境での展開後起動に合格。

8項目の結果と残件は[Windows検証記録](windows-ux-pr47-validation.ja.md)を参照してください。

長時間の読書感、Ctrl+クリック、アプリ切替時のカーソル復帰、実操作での削除確定を
再確認する場合は上の欄を使ってください。全体合格は利用者の明示的な返答によるもので、
自動確認からの推定ではありません。Intel/AMDと別クリーンアカウントの正式版ゲートは残ります。
