## 実機確認

環境はUbuntu 26.04.1、GNOME Shell 50.1、Wayland、NVIDIA GTX 1060 6GB。
Qtの論理画面は3072×1728、devicePixelRatioは2.0（小数倍率の確認ではない）。
Ubuntu 24.04 CIで作った同じ配布物をこの実機でも起動している。
本棚・設定・キャッシュの保存先を専用ディレクトリへ分け、`demo/`のPepper&Carrot 3冊と
40ページの生成画像だけを登録した。

2026-10-15に利用者から「確認しました。mainにまーじ」と候補版の全体合格と
マージ指示を受領した。依頼した確認項目は次のとおり。細目それぞれの個別実施報告は
受けていないため、全項目の個別合格としては記録しない。

- 全画面カーソルの2秒後非表示と、入力／フォーカス変更／全画面解除時の復帰。
- 読書情報の「本棚へ」と読書位置保存。
- Ctrl / Shift選択、右クリック位置、削除確認1回、元ZIP保持。
- ページ送り後10秒程度の連続目視でのちらつき、カラー保持、`O`比較。
- Screenshot / GlobalShortcuts権限、Alt+C / Alt+U、コントローラ復帰、CBZ出力順。

## 残件と判定の限界

- AMD / Intel実GPU、実デスクトップのX11セッション、他のWaylandコンポジタは未確認。
- コンテナのCPU Vulkan合格やXvfb合格は、実GPU・実デスクトップの合格を意味しない。
- 起動時にホスト側GIOの`libgvfsdbus.so`と同梱GLibのシンボル不一致、およびQt側の
  host portal ID登録済み警告が出た。起動は継続し、利用者から候補版の全体合格を受領した。
  警告の原因修正や、ファイル選択・キャプチャ許可それぞれの個別合格を意味しない。
- 再帰的な管理コピー削除は原子的ではなく、エラー時に部分削除が残りうる。
  失敗した本の登録と元アーカイブは保持する。使い捨てキャッシュ整理はbest-effort。
- 未署名のLinux previewとして公開する。正式版の検証完了とは扱わない。
