# 連番キャプチャ ヒューマンチェック

対象: macOS Apple Silicon版 MangaCrisp

著作権上問題のない自作画像、または `demo/` の Pepper&Carrot（CC BY 4.0）だけを
使用してください。

## 初回だけ行う設定

1. `MangaCrisp.app` を起動し、本棚の「画面を連番キャプチャ」を押します。
2. 「範囲を選択」で撮影対象を囲み、「撮影を開始」を押します。
3. macOSの確認が表示されたら「システム設定を開く」を押します。閉じてしまった場合は、
   Capture画面の「画面収録設定を開く」から同じ設定へ戻れます。
4. 「プライバシーとセキュリティ」の「画面とシステムオーディオ録音」または
   「画面収録」で MangaCrisp を有効にします。
5. macOSに「終了して再度開く」が表示された場合は押します。アプリが終了しない場合は、
   MangaCrispを通常どおり完全に終了して、同じ `MangaCrisp.app` をもう一度起動します。
6. 再起動後に、MangaCrispがシステムのプライベートウインドウや画面内容へアクセスする
   確認が表示された場合は「許可」を押します。この2段目の確認後は再起動不要です。
7. Capture画面の「画面収録権限」が「許可済み（撮影できます）」になったことを確認します。

配布版 `.app` と開発環境は別アプリとして扱われるため、配布版では初回に1度だけ
許可が必要です。また、未署名の開発版は再ビルドするとmacOS上の識別情報が変わるため、
同じ名前でも許可を取り直す場合があります。許可後のヒューマンチェック中は再ビルドせず、
同じ `MangaCrisp.app` を使ってください。画像や撮影情報はネットワークへ送信しません。

## 10ページ確認

1. `demo/` の Pepper&Carrot v01とv02を本棚へ登録し、v01から開きます。2冊で
   合計10ページあります。
2. 本棚から連番キャプチャを開き、セッション名を `Capture Human Check` にします。
3. 漫画のページ部分だけを「範囲を選択」で囲みます。通知用に画面上端か下端を
   70px程度、範囲外として残してください。
4. 「撮影を開始」を押します。Capture画面が最小化されたら対象の漫画へ戻ります。
5. `Command+Option+C` を押すたびに1枚保存します。範囲外の短い通知とDock上の数字が
   保存済み枚数です。v01の後は「次の巻へ」でv02を開き、10枚まで繰り返します。
6. 途中で `Command+Option+Z` を1回押し、直前の番号が取り消されることを確認します。
7. 同じ番号を撮り直し、最終的に10枚になることを確認します。
8. Capture画面へ戻り、サムネイルが `000001` から `000010` まで並ぶことを確認します。
9. 2枚をドラッグして順番を変え、同じ画面をもう一度撮って「要確認」が出ることを
   確認します。確認後、不要な重複ページは削除します。
10. `CBZ` と「完成後に本棚へ追加」を選び、「完成ファイルを作成」を押します。
11. 本棚で完成した本を開き、10枚がレビュー時の順番で読めることを確認します。
12. 「保存先を開く」で、完成CBZと `pages/000001.png` から `000010.png` が両方
    残っていることを確認します。

## 合格条件

- 撮影ショートカット1回につきPNGが1枚だけ増える。
- 高速に10回押しても欠番やUI停止がない。
- 取消後は同じ番号を再利用する。
- Capture通知が撮影範囲へ入らない。画面全体撮影時はDockの数字で確認できる。
- PNGとCBZでカラー、縦横、ページ順が維持される。
- CBZを本棚へ追加して読める。

失敗した場合は、発生した手順、画面収録設定、保存された枚数、警告文を記録します。
素材そのものや個人情報を含む画面はIssueへ添付しないでください。
