# Windows連番キャプチャ・単ページ表示ヒューマンチェック

更新日: 2026-08-13

対象: Windows 10/11 x64 Development Preview 0.7.1b0

権利または再配布許諾を持つ画像だけを使う。商用電子書籍、個人の漫画ライブラリ、
認証情報をテストデータにしない。

## 事前条件

1. ポータブルZIPを新しいフォルダへ展開する。
2. `MangaCrisp.exe`をダブルクリックして本棚が開くことを確認する。
3. `demo/`のPepper&Carrotまたは自作画像を用意する。
4. Windowsの表示倍率と使用ディスプレイを記録する。

## 連番キャプチャ

1. 本棚の「画面を連番キャプチャ」を開く。
2. 保存先、セッション名、ディスプレイを設定する。
3. 固定範囲を選び、表示された位置と寸法を確認する。
4. 既定の`Control+Alt+C`／`Control+Alt+Z`、または競合しないプリセットを選ぶ。
5. 「撮影を開始」を押す。対象アプリを前面にして、ページ送りは手動で行う。
   MangaCrispがタスクバーへ最小化され、アイコンをクリックすると管理画面へ戻れることを確認する。
6. 撮影キーを10回押し、`000001.png`から`000010.png`まで欠番なく保存されることを確認する。
7. 取消キーを1回押し、10枚目が取り消されることを確認する。
8. もう一度撮影し、`000010.png`として保存されることを確認する。
9. 対象アプリのフォーカスが奪われず、音とタスクバーの通知が撮影画像へ入らないことを確認する。
10. 「撮影を完了」でCBZを1個作成する。完成操作を繰り返しても重複生成されないことを確認する。

## 単ページ表示

1. 作成したCBZ、または`demo/`のPepper&CarrotをMangaCrispで開く。
2. `V`で「見開き（2画像）」から「単ページ（1画像）」へ切り替える。
3. 1画像だけが中央へ大きく表示され、通常のページ送りで1画像ずつ進むことを確認する。
4. `O`で原画／補正版を切り替え、単ページでも同じ画像を比較できることを確認する。
5. `V`でもう一度見開きへ戻ることを確認する。

## 停止条件

次のいずれかがあれば公開せず、結果と再現手順を記録する。

- キャプチャボタンが本棚に表示されない。
- 撮影開始後にMangaCrispがタスクバーから消え、管理画面へ戻れない。
- ホットキー登録に成功したのに反応しない、または他アプリのキー入力を奪う。
- 欠番、二重保存、取消後の番号ずれが発生する。
- 選択範囲とPNGの寸法・位置が一致しない。
- 黒画面など撮影できない対象を別経路で回避しようとする。
- CBZのページ順が連番と一致しない。
- 単ページ表示で2画像が出る、ページを飛ばす、原画比較が別ページになる。

このチェックはWindows実機の製品確認であり、Intel／AMDのReal-CUGAN証跡や、
Python未導入の別Windowsアカウント検証を代替しない。
